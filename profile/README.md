## Jerome Group

A small, deliberately-run set of repositories. Everything here is configured from code rather
than clicked into place: the organisation's settings, its branch protection, and its security
defaults live in one private management hub and are applied from there, so what you see is what
was written down and reviewed.

**How the work runs**

- Every change arrives as an issue, is triaged into one of five states, and lands as a pull
  request. Nothing goes straight to a default branch.
- Repositories are born from a template already carrying the conventions, so a new one is
  consistent from its first commit rather than after a cleanup.
- AI assistance is disclosed. Every commit and pull request names the model that helped in its
  trailers — and says so when none did, so silence is never the answer.

**Contributing**

[CONTRIBUTING](https://github.com/Jerome-Group/.github/blob/main/CONTRIBUTING.md) applies to
every repository here and says exactly how work flows. Security reports go to
security@jeromegroup.org — please do not open a public issue for a vulnerability
([SECURITY](https://github.com/Jerome-Group/.github/blob/main/SECURITY.md)).
